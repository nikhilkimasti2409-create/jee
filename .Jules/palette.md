## 2024-05-15 - Interactive Toggles to Buttons\n**Learning:** When converting `div` elements to `button` elements to improve accessibility, the layout can break because native `button` elements do not default to block-level and center their text. \n**Action:** Use utilities like `w-full text-left` in Tailwind to preserve the original layout of the element while ensuring the element is natively keyboard focusable and semantically correct.
